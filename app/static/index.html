      How it works

      Prove before act. Verify after act.

      FalkorDB isn't a picture here. Remove one edge and the same plan flips from PASS to BLOCK.

      G

      The graph is the context

      Identities, services, resources, credentials and invariants live in FalkorDB. Bounded Cypher reads return the exact multi-hop paths behind every decision.

      ⚖

      Deterministic verdicts

      Plans are projected in memory and checked against named invariants. The model proposes; code decides. The graph even suggests the repair.

      ✓

      Honest execution

      A person approves. Each step is read back from the graph. A timeout is UNKNOWN, a half-done run is PARTIAL_FAILURE, never a fake rollback.
